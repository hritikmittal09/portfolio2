### Motion and accessibility

The portfolio uses lightweight CSS animations and an Intersection Observer for
hero entrances, one-time scroll reveals, floating accents, and card hover effects.
No animation libraries or extra build steps are required for GitHub Pages.

- Animations run automatically without a manual pause toggle. The skills strip
  pauses while hovered or focused for readability.
- The site's animations respect the system's **reduced motion** preference,
  including changes made while the page is open.
- Scroll-reveal content stays visible if the animation script or Intersection
  Observer is unavailable. Skills and cards still use their existing JavaScript
  renderers.

### Experience

Edit [experience.js](./experience.js) to update the experience cards and keep the
latest role first. Each description can be a paragraph or an array of achievement
bullets; employment type and location are optional. Company images are stored in
[images](./images/).
